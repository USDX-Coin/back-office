# Components

Shared, reusable components used across multiple features.

## Structure

```
components/
  ├── ui/                    # shadcn/ui primitives — DO NOT EDIT MANUALLY
  ├── layout/                # App shell: Navbar, Sidebar, MobileNavDrawer, NavTree, navItems.ts, useNavBadges, MainLayout, ProfileDropdown, AuthGuard
  ├── record-modal/          # RecordModal + RecordStatus + RecordActions — modal detail tengah untuk SEMUA tabel (footer aksi menempel, ↑/↓)
  ├── ToneChip.tsx           # Chip status bernada act/bad/ok/wait (tabel + modal)
  ├── TabBar.tsx             # Tab di atas tabel (Transaksi)
  ├── table/                 # TableToolbar + popover Filter/Urut/Kolom + GroupedTable
  ├── PageHeader.tsx         # Judul halaman (Crimson Pro) + keterangan + slot aksi
  ├── WalletShort.tsx        # Wallet NASABAH ringkas (0x1234…abcd, mono kecil) + tombol salin — satu-satunya alamat yang boleh di depan (ops-fokus)
  ├── RouteNotice.tsx        # Tampilan 404/403 di dalam layout: "Kode n" + judul Crimson + kalimat + fakta label–nilai + tombol Ke Ringkasan
  ├── Avatar.tsx             # Initials + fixed 8-color palette
  ├── FieldError.tsx         # Inline form error primitive (role="alert")
  ├── TableEmptyState.tsx    # Table empty-state with no-data / no-results modes
  ├── DateRangeFields.tsx    # Two date inputs (+ optional maxDays / maxDate message) — reports toolbar + BNI statement panel
  ├── StatusPill.tsx         # Label badge for a StatusConfig (tanpa titik sejak revisi PM 9 Okt)
  ├── DataList.tsx           # DataSection/DataField — label–nilai satu baris per pasangan (modal, sheet)
  ├── FormLayout.tsx         # FormSection/FormField/FormFooter — form gaya Stripe, tombol kanan bawah
  ├── FormDialog.tsx         # Bingkai form "ubah …" di dialog (pola halaman pengaturan, 11 Okt 2026)
  ├── OptionCombobox.tsx     # Combobox cmdk untuk daftar pilihan tetap yang panjang (> 15)
  ├── DataTable.tsx          # Generic data table with filter-toolbar slot
  └── useDataTableParams.ts  # URL-state hook for tables that compose their own toolbar
```

## Rules

- **`ui/`** — Generated by `npx shadcn@latest add <component>`. Do not modify these files directly. Customizations go in consuming components or via Tailwind theme tokens in `src/index.css`.
- **`layout/`** — App-wide layout components. `MainLayout` renders `Navbar` + `Sidebar` + `<Outlet />` (+ banner mode uji mint). Menu didefinisikan SEKALI di `navItems.ts` (`NAV`: Ringkasan · Transaksi · OTC ▸ · Nasabah ▸ · Keuangan ▸ · Pengaturan ▸) dan dirender oleh `NavTree` di Sidebar desktop maupun `MobileNavDrawer` ponsel — jangan menambah entri menu di tempat lain. `useNavBadges` menghitung badge per `BadgeKey`; grup tertutup menjumlah badge anaknya. `breadcrumbFor` menyusun breadcrumb dari tabel menu (tidak pernah dari URL) sebagai `{ label, to? }`; `Navbar` menautkan segmen ber-`to` kecuali segmen terakhir (`aria-current="page"`), nama grup tetap teks (11 Okt 2026). Jangan tambah tombol "← Kembali" di halaman turunan — breadcrumb itulah jalan baliknya. `AuthGuard` provides `ProtectedRoute` (tanpa sesi → `/login?next=…`; sesi habis menambah state `sessionExpired`; setelah Keluar → `/login` polos), `PublicRoute` (sudah masuk → `next` yang lolos `safeNextPath`, selain itu Ringkasan) dan `RoleGuard` (peran terlarang → `ForbiddenPage` di tempat, bukan pengalihan). Profile is reachable only via `ProfileDropdown` in the navbar — no sidebar entry.
- **Klik baris = modal tengah (PM 11 Okt 2026)** — tidak ada panel samping di mana pun; tabel selalu lebar penuh. `detail-panel/` (SplitView, DetailPanel) sudah dihapus — jangan dibuat ulang.
- **`record-modal/`** — `RecordModal` (10 Okt 2026; dipakai Transaksi, OTC, Antrean Tanda Tangan, Verifikasi, Daftar Nasabah, Jejak Audit): `Dialog` `max-w-3xl` dengan header judul + subjudul, isi menggulir (`DialogBody`), footer `DialogFooter` yang tidak ikut menggulir: kiri navigasi ↑/↓ + "n dari N" (`nav`), kanan `actions`. Panah ↑/↓ dan `k`/`j` didengar di `window` (fokus bisa jatuh ke `<body>` setelah tombol jadi mati) tapi diabaikan saat fokus di isian/menu dan saat dialog lain bertumpuk di atasnya (dialog terbuka paling akhir di DOM harus modal ini). `locked` mematikan Esc/klik luar selama transaksi berjalan. `walletSafe` (OTC, Antrean Tanda Tangan): dialog NON-modal + tirai sendiri; klik/fokus/Esc di jendela wallet RainbowKit (`[data-rk]`) tidak menutup modal — modal Radix biasa membuat jendela wallet tidak bisa diklik. Pasang di SEMUA cabang render satu modal (memuat/isi), karena berganti mode = konten dipasang ulang. `RecordStatus` = kotak chip + "Yang perlu kamu lakukan". Pemanggil memegang URL (`/x/:id`) dan memakai `navigate(..., { replace: true })` untuk ↑/↓; state per baris di dalam modal dibuang SAAT RENDER saat id berganti.
- **`TabBar`** — tab garis bawah di atas tabel; angka di label sebagai teks (`Perlu tindakan (3)`) supaya nama aksesibelnya utuh.
- **`RecordActions`** (`record-modal/`) — isi footer modal: SATU tombol utama (paling kanan) + menu "Lainnya"; aksi berisiko memakai konfirmasi inline "Sudah benar semua?"; `override` mengganti seluruh bilah (mis. konfirmasi hapus nasabah). Pasang `key={idBaris}` supaya konfirmasi setengah jalan tidak terbawa saat ↑/↓. Menu "Lainnya" = `DropdownMenu modal={false}` (11 Okt 2026): versi modal di dalam Dialog meninggalkan `pointer-events: none` di `<body>` saat item memanggil `navigate()`. Dropdown lain yang item-nya pindah halaman (menu berkas Verifikasi, `ProfileDropdown`) juga `modal={false}`.
- **`table/GroupedTable`** — grup "Perlu tindakan" di atas riwayat, kolom sekunder `hidden sm:table-cell`, lebar minimum hanya ≥ sm supaya Status muat di ponsel.
- **`ToneChip`** — satu kosakata warna status (`lib/tone.ts`: act emas, bad merah, ok hijau, wait netral), gaya dasar `STATUS_CHIP_BASE`.
- **`Avatar`** — Initials only (no uploaded images in v1). Background hue indexed by `name.charCodeAt(0) % 8` from a fixed palette.
- **`FieldError`** — Renders `<p role="alert">` with `text-destructive` styling when `message` is non-empty; null otherwise.
- **`TableEmptyState`** — Two modes: `no-data` (default empty surface, optional CTA) and `no-results` (filtered with optional Clear-filters affordance).
- **`DataTable`** — Generic table accepting `ColumnDef<T>[]`, data, rowCount. Features: arbitrary `filterToolbar` slot, custom `emptyState` slot, pagination, sort, URL-state via `useDataTableParams`, loading skeletons, no-line styling (baris dipisah isian, bukan garis). Default toolbar (search + statusOptions + date range) renders only when no `filterToolbar` is provided.
- **`DateRangeFields`** — Renders a fragment of two labelled `type="date"` inputs (`<idPrefix>-start-date` / `-end-date`) so the parent grid keeps its layout. Rules live in `lib/dateRange.ts`; the component only shows the message (`showMessage={false}` keeps the reports toolbar silent).
- **`StatusPill`** — Label badge (no dot). Base class = `STATUS_CHIP_BASE` (`lib/statusChip.ts`), shared with `ToneChip`, `ui/badge`, and every local status badge — one status style (audit font 10 Okt 2026).
- **`DataList`** — Every label–value block in a modal/sheet uses `DataSection` + `DataField` (one pair per row, hairline dividers, container-query stacking). Do not write another local `Field`.
- **`FormDialog`** (11 Okt 2026) — bingkai dialog untuk form ubah di halaman pengaturan: judul + keterangan, isian menggulir (`DialogBody`), footer menempel dengan kalimat akibat kiri + Batal + tombol kirim kanan; tidak bisa ditutup selama `pending`. Isian, validasi, dan dialog konfirmasi tetap milik pemanggil (konfirmasi bertumpuk di atasnya). Dibuka dari tombol di kanan atas kartu "saat ini" (`action` di `CurrentRateCard`, `CurrentFeeConfigCard`, `CurrentThresholdCard`, `CurrentControlsCard`, `ReserveBalanceCard`).
- **`FormLayout`** — Page/card forms compose `FormSection` (grouped fields) + `FormField` (label, hint, error) + `FormFooter` (consequence note left, buttons right). Never a full-width submit button.
- **`DataTable` on phones** — below 640px rows render as cards (first column = title, rest label–value) via `useMediaQuery`; jsdom has no matching media query, so unit tests keep seeing the table.
- **`useDataTableParams`** — Lives in its own file (Fast Refresh requires component-only files). Reads page/sortBy/sortOrder/search from URL; provides `updateParams` and `clearAll`.

## DataTable Props

| Prop | Type | Description |
|------|------|-------------|
| `columns` | `ColumnDef<T>[]` | TanStack Table column definitions |
| `data` | `T[]` | Current page data |
| `rowCount` | `number` | Total row count (for pagination) |
| `isLoading` | `boolean` | Shows skeleton rows |
| `statusOptions` | `{value, label}[]` | Default-toolbar status select options |
| `onExportCsv` | `() => void` | Default-toolbar CSV export callback |
| `pageSize` | `number` | Default 10 |
| `filterToolbar` | `ReactNode` | Custom filter toolbar; replaces the default search+status+date toolbar when provided |
| `emptyState` | `ReactNode` | Custom no-data slot (e.g., illustration + Add CTA) |
| `hasFilters` | `boolean` | Override; when true and rowCount=0, renders the no-results empty state with Clear-filters link |
| `getRowId` | `(row, index) => string` | Stable row identity for client-paginated data without a unique field (BNI statement rows repeat `journalNo`); defaults to the TanStack index id |
